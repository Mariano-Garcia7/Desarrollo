# Comandos de Linux y Ubuntu

## Descripción

En este apartado se encuentra una recopilación de los comandos más utilizados en la terminal de **Linux y Ubuntu**, junto con una breve descripción de su funcionamiento y utilidad.

El objetivo de este documento es contar con una guía de consulta rápida que facilite el uso de la consola, la administración del sistema y la ejecución de tareas comunes.

## Contenido

- Comandos básicos de navegación por directorios.
- Administración de archivos y carpetas.
- Gestión de permisos y usuarios.
- Instalación y actualización de paquetes.
- Administración de procesos y servicios.
- Comandos de red y diagnóstico del sistema.
- Otros comandos útiles para el entorno Linux.

## Actualizaciones

Este documento se actualizará continuamente conforme se adquieran nuevos conocimientos y se aprendan comandos adicionales, incorporando ejemplos y explicaciones que permitan ampliar la documentación.

**Nota:** Este repositorio tiene fines educativos y de consulta personal, por lo que su contenido evolucionará progresivamente con la práctica y el aprendizaje.
