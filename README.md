# Desarrollo

Proyectos de software que construyo con el ecosistema .NET, enfocados en
arquitectura de microservicios, APIs y aplicaciones multiplataforma.

## Tecnologías
C# · ASP.NET · .NET MAUI · PostgreSQL · Docker · GitHub Actions

## Proyectos
- **facturacion-microservicios:** sistema de facturación con arquitectura
  de microservicios, contenedores Docker y datos de ejemplo.
- **app-maui-pos:** aplicación multiplataforma de punto de venta.
- **api-buenas-practicas:** API con autenticación, pruebas unitarias e
  integración continua.

> Todos los proyectos usan datos ficticios y fueron creados desde cero
> con fines de portafolio.
